# 实验方法与判断口径

## 控制变量

每个决策点固定六人桌、每人初始 100BB、无前注、无抓注，以及 Hero 位置、底牌、公共牌、完整历史。三种风格仅改变 `strategy_profile.target_profile_name` 和请求追踪 ID。翻前用 VPIP/PFR 档位，翻后用 AF/WTSD 档位。

请求沿用原普通 lookup 的协议、阈值、菜单和随机扰动设置，省略 `request_profile`，不执行业务玩家前后置钩子。只设置当前 Hero 的档位，不设置全桌对手的风格。

历史是反事实对照：不要求每种风格此前必然走到相同节点。场景均先重放校验，待查询动作不写进历史。

## 成功条件和缓存

HTTP 成功不等于求解成功。检查错误字段、非空策略、有效概率/EV、重复动作、Hero 座位及服务端档位回显。GTO 回显 `gto` 或 `no_profile_applied` 按均衡基线处理。

默认每组重复两次。每次完整请求与响应先原子保存，结束后生成 HTML/Markdown。离线重建使用保存的场景与计划快照；缓存损坏时拒绝复用，不静默重新请求。

## 比较内容

- 汇总为弃牌、跟注、过牌、主动四类概率；主动是下注、加注和全下之和，重复请求取均值。
- 完整候选按动作类型、金额、底池比例、座位对齐，比较概率、EV、菜单及结构变化。
- 同一动作缺失时，概率按 0 对齐，EV 不补 0。整个风格无有效样本时显示缺失，不填为 0%。
- 最高概率动作与接口实际推荐分开观察。推荐相同也可能有很大的策略分布差异，单次推荐不同也不能直接认证风格。

## 相对 GTO 的方向检查

实现位于 `src/analysis/style.ts`，沿用原工具已经验证的算法。

- 翻前：松弱更愿继续且更少主动；紧凶更少继续，继续后的主动比例更高。
- 翻后：松弱总主动概率不高于 GTO，紧凶总主动概率不低于 GTO。
- 容差为 0.5 个百分点；翻前任一比较侧继续概率低于 1% 时，不使用条件主动比例判反向，避免极小分母引起误报。
- 继续概率直接累计跟注、过牌、主动，避免弃牌概率舍入到 1 后丢掉小概率。BB 免费过牌不等于自愿入池，因此此指标和样本均值不是长期 VPIP/PFR。
- 完整 HTML 中将样本分为方向符合预期、差异不明显、反向变化、数据不全和模型来源变化。反向场景保留完整数据供解释，不强行归为失败。

## 已有正式实验

迁入实验共 100 场景、600 次成功请求：89 条方向符合预期，10 条差异不明显，1 条需复核。T03 中紧凶因更常弃牌而降低总主动概率，但继续后的主动比例仍接近 100%；这说明方向检查不能代替完整风格理解。

结论仅限所选历史与当时服务版本，不代表所有牌局或玩家长期行为。两次重复只是初步波动观察，不能当作抽样频率的统计显著性验证。
