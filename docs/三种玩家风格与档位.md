# 三种玩家风格与档位

统一条件：6 人桌、初始 100BB、无前注、无抓注，对应 `2-0 / 4-6p`。本工具只设置当前决策 Hero 的策略档位，不设置全桌每位对手的风格。

## 固定档位

| 风格 | 翻前 profileName | 翻后 profileName |
| --- | --- | --- |
| 松弱 | `vpip68-pfr7` | `af0.5-wtsd79` |
| 紧凶 | `vpip22-pfr16` | `af5.8-wtsd46` |
| GTO | `gto` | `gto` |

## 选择依据

- 松弱：翻前选择入池宽且 PFR 最低的组合；翻后选择 AF 最低、WTSD 最高的档位，突出被动跟注和频繁摊牌。
- 紧凶：翻前选择 VPIP 很低、PFR/VPIP 较高的组合；翻后选择 AF 最高、WTSD 最低的档位，突出选择性入池与主动进攻。
- GTO：翻前和翻后均使用内置 gto，作为均衡基线。GTO 的概率无需始终介于另外两种风格之间。

## 应用与解释

- 配置来源：`src/profiles/styles.ts`；指标快照：`src/profiles/strategyProfile.catalog.ts`。不引用原项目的玩家类型映射。
- 传递字段为 `strategy_profile.target_profile_name`，与请求预设 `request_profile` 不同。
- 固定历史是反事实比较，不要求三种风格从翻前开始必然采取同样历史。翻后档位与翻前档位是独立选择，不代表组合后实测 VPIP/PFR。
- 以服务端 matched_profile_name 验证生效；GTO 的 no_profile_applied 按均衡基线处理。
- 完整概率、最高概率动作和实际 suggested_action 分开观察，具体判断口径见《实验方法与判断口径》。
