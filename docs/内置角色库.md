# 内置角色库

在“玩家配置库 → 内置角色库”浏览 75 种角色。方案版本为 `2026-11-26-v1`，对应《玩家风格75种组合档位方案.md》。15 个翻前代表与 5 个翻后代表的映射维护于 `src/profiles/styles.ts`，参考指标直接读取本仓库 catalog 的 `2-0 / 4-6p` 分组。

支持卡片、完整参数表、5×3 组合矩阵，按三个维度和编号、名称、profileName 筛选，可按各指标排序；最多勾选 4 个角色对比。矩阵默认展示翻后基线，通过翻后风格筛选切换其余组合。“划分标准”解释区间、代表选取和近似偏差；详情展示每个角色的指标、档位、来源与版本。

所有数值均为对应街道的档位参考数据，未把拼接值当作完整组合实测 HUD。75 种完整组合尚未全部实测验证；实际牌局结果须另看 Session 和样本量。只有 `L3-A2-F3` 的翻前翻后都为 gto。原紧凶、原松弱分别对应 `L1-A3-F5`、`L4-A1-F1`。

## 三种使用入口

- **复制为我的玩家配置**：打开现有玩家编辑器，生成新的唯一 ID，可修改后保存。不会自动保存或替换已有玩家，现有配置库最多 8 个的规则保持不变。
- **加入实验草稿**：不占用已保存玩家配置的名额，角色快照单独保存在浏览器草稿的可选 `rolePlayers` 中。选择仍受每次实验最多 8 个玩家限制。保存实验才写入新的实验目录；执行仍需显式点击。
- **从草稿移除**：实验设置中的所有玩家卡片均提供此按钮，包含临时角色、个人配置及预设，选中与未选中的玩家均可移除。同步移除本次选择，临时角色移除草稿快照，个人配置通过草稿的可选 `hiddenPlayerIds` 保持隐藏；刷新后仍保持移除状态，不删除个人配置或历史实验。“恢复已移除的个人玩家”可恢复卡片，恢复后需自行勾选；临时角色可从内置库再次添加。取消勾选则仅停止参与本次实验，卡片仍留在草稿中。
- **填入牌桌座位设置**：只改变前端待应用配置，需在牌桌点击保存设置（下手生效）或开始新体验。选择角色不会自动配置正在运行的牌桌或发送 solver 请求。

## 兼容与来源

内置模板不自动追加到 `settings.players`。复制、实验及牌桌的 `PlayerConfig` 可包含可选字段 `sourceRole: { id, version }`，标记来源；编辑后的副本保留来源，但不能据此视为未经修改的内置角色。没有该字段的旧玩家和实验继续按原方式读取，无需迁移或重写。

新实验、牌桌保存实际选用的配置快照，后续修改个人配置不会改写历史实验。复制包含内置角色的实验时，保留尚未在个人配置库中的角色快照。普通浏览、筛选、对比及三种使用入口均不触发第三方请求。
