# 策略配置文档 (Strategy Profiles)

本文档展示了基于 GTO（博弈论最优）基准策略进行自我对战模拟（Self-play simulations）得出的策略配置数据。



## 1. 理解指标 (Understanding the Metrics)

### 翻前指标 (Preflop Metrics)

- **Target VPIP (目标 VPIP)**: 主动入池（Voluntarily Put money In Pot）手牌的目标百分比。

- **Target PFR (目标 PFR)**: 翻前加注（Pre-Flop Raise）的手牌目标百分比。

- **Empirical VPIP (实测 VPIP)**: 在自我对战模拟中实际达到的 VPIP 数值。

- **Empirical PFR (实测 PFR)**: 在自我对战模拟中实际达到的 PFR 数值。

- **$BB/100$**: 每 100 手牌赢得的大盲注数（相对于 GTO 基准）。

  

### 翻后指标 (Postflop Metrics)

- **Target WTSD (目标 WTSD)**: 摊牌（Went To ShowDown）手牌的目标百分比。

- **Target AF (目标 AF)**: 目标激进指数（Aggression Factor，激进动作与被动动作的比率）。

- **Empirical WTSD (实测 WTSD)**: 在自我对战模拟中实际达到的 WTSD 数值。

- **Empirical AF (实测 AF)**: 在自我对战模拟中实际达到的 AF 数值。

- **$BB/100$**: 每 100 手牌赢得的大盲注数（相对于 GTO 基准）。

  

## 2. 游戏格式标记 (Game Format Notation)

游戏格式采用 **X-Y** 的标记方式：

- **第一个数字 (X)**: 盲注数量 ($2=SB+BB$, $3=SB+BB+$ 抓头/Straddle)。

- **第二个数字 (Y)**: 前注（Ante）占大盲注（BB）的百分比 ($0=$ 无前注, $50=$ 半个 BB, $100=$ 满 BB)。

  

**示例:**

- **2-0**: 2 个盲注，无前注。

- **2-50**: 2 个盲注，50% BB 前注。

- **3-50**: 3 个盲注，50% BB 前注。

  

### 可用的游戏格式 (Available Game Formats)

- **2-0**: 2 盲注，无前注 

- **2-50**: 2 盲注，50% BB 前注

- **2-100**: 2 盲注，100% BB 前注

- **3-0**: 3 盲注，无前注

- **3-50**: 3 盲注，50% BB 前注

  

完整的策略配置表附在本文档底部，按格式分类并分为翻前和翻后部分。



## 3. 集成说明 (Integration Notes)

### 发布信息 (Release Information)

- **翻后策略配置 V2** 将于 **2026年1月7日** 向 B2B 客户开放。

  

### 请求格式 (Request Format)

策略配置 V2 使用与 V1 相同的请求结构。请在请求中包含 `strategy_profile` 对象：

```json
{
  "request_id": "unique-request-id",
  "hand": {...},
  "strategy_profile": {
    "target_profile_name": "wtsd51-af1.2"
  }
}
```

**重要提示：** 请确保配置类型与游戏阶段相匹配：

- 翻前配置 (Preflop profiles) $\rightarrow$ 翻前游戏 (Preflop games) 

- 翻后配置 (Postflop profiles) $\rightarrow$ 翻后游戏 (Postflop games) 

  

### 验证配置应用情况 (Verifying Profile Application)

请检查响应中的 `solution_information.strategy_profile_config` 字段以确认配置是否生效。



**当配置未应用时 (When profile is not applied):**

```json
{
  "request": {},
  "strategy": {<default results>},
  "solution_information": {
    "strategy_profile_config": {
      "game_format": "no_profile_applied",
      "matched_profile_name": "no_profile_applied",
      "strategy_after_adjust": "no_profile_applied",
      "strategy_before_adjust": "no_profile_applied"
    }
  }
}
```



**当发生回退时 (When fallback occurs):** `game_format` 字段将显示实际使用的回退格式：

```json
{
  "solution_information": {
    "strategy_profile_config": {
      "game_format": "3-50", // 此处显示实际使用的回退格式
      "matched_profile_name": "vpip21-pfr13"
    }
  }
}
```



## 4. 游戏格式回退机制 (Game Format Fallback Behavior)

策略配置 V2 包含针对**现金局 (Cash Games)** 的自动回退功能：

### 默认回退格式 (Default Fallback Format)

- **回退格式**: **3-50** (3 盲注，50% BB 前注)。

- 这是当请求的游戏格式不可用时使用的默认回退格式。

  

### 何时发生回退 (When Fallback Occurs)

回退机制将在以下场景自动激活：

1. **未找到请求的游戏格式 (Requested game format not found)** 

   - 如果您的游戏格式（例如 2-75）在策略配置中不存在。

   - 系统会自动回退到 **3-50** 格式。

   - 请求将使用回退后的配置成功返回。

     

2. **请求的游戏格式存在但为空/无效 (Requested game format exists but is empty/invalid)** 

   - 如果游戏格式存在但没有有效的策略配置。

   - 系统会自动回退到 **3-50** 格式。

   - 请求将使用回退后的配置成功返回。

     

### 回退限制 (Fallback Limitations)

- **MTT 锦标赛**: MTT 游戏**禁用**回退功能。

- MTT 游戏使用 **2-15** 格式，如果未找到将直接失败（无回退）。

- 这确保了 MTT 游戏不会意外使用现金局的策略配置。

  

### 验证回退使用情况 (Verifying Fallback Usage)

检查 `solution_information.strategy_profile_config` 中的 `game_format` 字段：

- 如果显示 **3-50** 但您请求的是其他格式，说明使用了回退。

- `matched_profile_name` 将显示实际应用的配置名称。

  

## 5. 错误处理与快速参考 (Error Handling & Quick Reference)

### 错误处理行为 (Error Handling Behavior)

1. **不存在的配置名称 (Non-existent Profile Names)** 

   - 请求成功，返回默认 GTO 策略。

   - 响应状态包含 `no_profile_applied`。

   - 服务不会中断。

     

2. **配置类型不匹配 (Profile Type Mismatch)** 

   - 在翻后游戏中使用翻前配置，或反之：

   - 请求成功，返回默认 GTO 策略。

   - 响应状态包含 `no_profile_applied`。

   - 配置被忽略。

     

3. **MTT 锦标赛请求 (MTT Tournament Requests)** 

   - **警告**: 策略配置 V2 仅适用于现金局。

   - 带有 V2 配置的 MTT 请求将**失败**。

   - MTT 请使用策略配置 V1（支持 2-15 游戏格式）。

     

### 快速参考表 (Quick Reference)

| **场景**                        | **请求结果** | **响应状态**       | **应用的策略**          |
| ------------------------------- | ------------ | ------------------ | ----------------------- |
| 有效配置 + 正确游戏类型         | 成功         | 显示配置名称       | 调整后的策略            |
| 无效配置名称                    | 成功         | no_profile_applied | 默认 GTO                |
| 翻前配置 $\rightarrow$ 翻后游戏 | 成功         | no_profile_applied | 默认 GTO                |
| 翻后配置 $\rightarrow$ 翻前游戏 | 成功         | no_profile_applied | 默认 GTO                |
| 不可用的游戏格式 (现金局)       | 成功         | 回退至 3-50        | 调整后的策略 (来自回退) |
| 不可用的游戏格式 (MTT)          | 失败         | 错误响应           | N/A                     |
| V2 配置用于 MTT                 | 失败         | 错误响应           | N/A                     |
