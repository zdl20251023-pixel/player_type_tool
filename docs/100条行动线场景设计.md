# 三种玩家风格：100 条行动线场景设计

本文只描述场景语义，不包含接口请求参数，不预设 AI 应当选择的动作。

## 统一约定

- 6 人桌，每位玩家本手开始时均为 **100BB**，小盲 0.5BB、大盲 1BB，**无前注、无抓注**。
- 位置顺序为 **UTG → HJ → CO → BTN → SB → BB**。翻后从仍在局中的 SB/BB 开始，沿座位顺序行动。
- Hero 是本条场景的待决策玩家。历史止于 Hero 行动之前；表中后续没有写出的玩家尚未行动，不能默认其弃牌。
- 所有金额均以 BB 表示；“加注到”是本街累计投入的总额，“下注”是本次下注金额，“跟注”表示补足差额。盲注不重复列入历史。
- 底牌与公共牌使用 `As` 等记法：`s=黑桃、h=红桃、d=方块、c=梅花`，`T=10`。未知对手底牌不指定。
- 每条历史分别供松弱、紧凶、GTO 三种风格使用，保持 Hero 的位置、底牌、公共牌和历史完全一致。固定历史不表示三种风格此前必然采取相同行动。
- 同一底牌在不同条目中可以复用；同一条目内底牌和公共牌不得重复。

| 风格 | 翻前档位 | 翻后档位 |
| --- | --- | --- |
| 松弱 | `vpip68-pfr7` | `af0.5-wtsd79` |
| 紧凶 | `vpip22-pfr16` | `af5.8-wtsd46` |
| GTO | `gto` | `gto` |

## 覆盖分布

| 阶段 | 类别 | 数量 |
| --- | --- | ---: |
| 翻前 | 未开池：open、limp 或 fold 决策 | 14 |
| 翻前 | 面对 open：fold、call 或 3bet 决策 | 16 |
| 翻前 | 面对 3bet：fold、call 或 4bet 决策 | 12 |
| 翻前 | 跛入底池、隔离加注、挤压加注、冷面对 3bet | 8 |
| 翻后 | 翻牌决策 | 24 |
| 翻后 | 转牌决策 | 16 |
| 翻后 | 河牌决策 | 10 |
| **合计** | **翻前 50、翻后 50** | **100** |

翻前覆盖全部六个位置；翻后覆盖有位置/无位置、主动方/防守方、单加注/3bet/多人底池，以及强牌、边缘成牌、垃圾牌和不同听牌。这里不做所有维度的完全笛卡尔组合。

为减少重复，以下每条翻后场景引用一个完整的翻前模板。模板结束后才发翻牌，未列为继续的玩家都已明确弃牌。所有玩家仍以本手初始 100BB 为起点；模板及后续下注会扣减剩余筹码。

## 后续比较口径

- 每条场景比较完整候选动作、尺寸、概率、EV、最高概率动作及接口实际推荐；实际请求和参数转换不在本文范围内。
- 对比应分清“推荐动作不同”与“推荐相同但概率不同”，不强求每条都产生三种不同动作。
- 紧凶可能直接弃掉边缘牌；GTO 也可能比紧凶更常下注某一手牌。判断风格应结合范围选择、继续后的主动性及多个场景。
- 听牌信息以当前决策街道为准。后门听花不等于翻牌直接听花；已到转牌且不足四张同花时，不能再称为可以一张河牌完成的同花听牌。
- 本文中的历史用于反事实对照；尤其是边缘牌跟注后才改善的场景，不要求每种风格从翻前起都会走到同一节点。
