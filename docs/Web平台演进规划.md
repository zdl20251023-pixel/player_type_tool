# Web 平台演进规划

本机单用户 Web 首版已实现，使用 Bun HTTP 服务与 TypeScript 浏览器界面，不引入数据库、Redis 或外部工作区依赖。使用方式见 [Web 工具使用与实现说明](Web工具使用与实现说明.md)。

## 已实现的共享边界

| 模块 | 职责 |
| --- | --- |
| client | solver HTTP 客户端及 DeepSeek / Gemini REST 适配；每次实验启动时创建 solver 客户端 |
| profiles | 原始 catalog 快照只读；适用桌型筛选、档位校验与玩家组合 |
| scenarios | 固定桌型构造、路线解析、生成结果校验与合法性重放 |
| runner | CLI 参数编排、共享缓存执行器、Web 实验及模型步骤编排 |
| storage | 兼容 session v1；Web 设置、密钥、提示词版本和调用快照 |
| analysis | 概率、EV、结构差异、风格判断、提示词模板 |
| reports | 旧版三风格报告、任意玩家横向数据和可离线 HTML |
| web | 本机 HTTP API、页面与交互 |

## 后续扩展

1. 扩展桌型、深度、前注或其他 solver 参数时，同步更新请求契约、catalog 约束与合法性重放；不发送未支持字段。
2. 大批量分析按上下文预算拆分场景，再归纳总报告。
3. 在已有快照与缓存机制上增加取消、调度、并发控制与更细粒度失败修复。
4. 确有远程或多人需求时，再增加鉴权、用户隔离、任务队列和数据库。

报告重建与模型结论分析只读取已有 solver 缓存。旧 CLI 目录和默认 100 条场景继续保留。
