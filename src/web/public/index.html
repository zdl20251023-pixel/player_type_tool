          PLAYER STYLE / HUD REFERENCE
          
玩家风格指标说明

        

        

      

      

        

          VPIP / PFR 看翻前范围与加注倾向，AF / WTSD
          看翻后主动性与摊牌倾向。四项结合阅读，才能形成玩家画像。
        

        

          

            

              
VPIP 自愿入池率

              翻前 · 百分比
            

            
Voluntarily Put Money In Pot

            
翻前自愿投入筹码的手牌占比，包括跟注、跛入和加注，用于观察玩家的松紧程度。

            
VPIP = 自愿投入筹码的手牌数 ÷ 可统计手牌数 × 100%

            
    
              
  • 被迫支付的大小盲注、前注不计为自愿投入。
    • 
              
  • 大盲位只过牌、没有自愿补入筹码，不计入 VPIP。
    • 
              
  • 通常数值越高，参与的牌越多、范围越松。
    • 
            

          

          

            

              
PFR 翻前加注率

              翻前 · 百分比
            

            
Pre-Flop Raise

            
翻前至少加注过一次的手牌占比，包括首次加注、3-bet、4-bet 等，用于观察翻前主动性。

            
PFR = 翻前有加注的手牌数 ÷ 可统计手牌数 × 100%

            
    
              
  • 按手牌统计；同一手多次加注不会重复计为多手。
    • 
              
  • 和 VPIP 一起看：VPIP 高、PFR 低，通常说明较多跟注或跛入。
    • 
              
  • 两者差距小，说明自愿入池中较多采用加注。
    • 
            

          

          

            

              
AF 激进系数

              翻后 · 比值
            

            
Aggression Factor

            

              比较翻牌、转牌和河牌上的下注、加注次数与跟注次数，衡量翻后主动行为相对跟注的程度。
            

            
AF =（下注次数 + 加注次数）÷ 跟注次数

            
    
              
  • 过牌和弃牌不进入这个公式；AF 不是百分比。
    • 
              
  • AF = 3，表示统计中下注与加注的总次数是跟注的 3 倍。
    • 
              
  • 跟注次数为 0 时，不应直接理解成 AF = 0；显示方式取决于软件。
    • 
            

          

          

            

              
WTSD 摊牌率

              翻后 · 百分比
            

            
Went To Showdown

            
在已经看到翻牌的手牌中，最终进入摊牌的比例，用于观察玩家继续到摊牌的倾向。

            

              WTSD = 看过翻牌且进入摊牌的手牌数 ÷ 看过翻牌的手牌数 × 100%
            

            
    
              
  • 翻前已经弃牌的手牌不进入分母。
    • 
              
  • 较高可能表示更愿继续到底；较低可能表示翻后更容易弃牌，需结合牌力与其他指标。
    • 
              
  • 不是摊牌胜率 W$SD，也不能单凭此项判断玩家水平。
    • 
            

          

        

        

          
组合解读示例

          

            

              VPIP 22% / PFR 18% / AF 2.5较紧、翻前以加注入池为主，可作为紧凶倾向的示例。
            

            

              VPIP 45% / PFR 5% / AF 1入池较松、翻前加注较少、翻后较被动，可作为松弱／跟注站倾向的示例。
            

          

          

            这是理解组合关系的示例，不是强制分类标准。人数、位置、级别和样本量都会影响解读；满员桌的经验阈值不能直接套用于本工具的
            6 人桌。
          

        

        

          
在本工具中如何使用

          

            翻前选择 VPIP / PFR 档位，翻后选择 AF / WTSD 档位。catalog 的数值是上游快照，profileName
            中的数字不保证等于实际指标。
          

          

            单条场景的“弃／跟／过／主动”概率与动作 EV，不是长期 HUD 统计。选择一个档位也不代表某个场景的跟注率、加注率必须等于该指标。
          

        

        

          分母、无行动机会及零分母等边界处理以具体 HUD 软件和上游统计口径为准。定义参考
          DriveHUD 指标说明 ↗。本弹窗仅提供说明，不修改配置或发送模型请求。
